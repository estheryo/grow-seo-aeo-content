# Audit and page-brief method

## Citation-gap table

Use one row per prompt and engine.

| Field | Meaning |
|---|---|
| Prompt | Exact tested question |
| Engine / locale / date | Reproducibility context |
| Cited winners | Domains and canonical URLs observed |
| Lifted evidence | Facts or passages the answer relies on |
| Target owner | Existing or proposed canonical page |
| Missing entities | Products, concepts, audiences, locations, or alternatives absent from the target |
| Missing evidence | Data, examples, methods, proof, or independent corroboration absent from the target |
| Structure gap | Answer placement, headings, tables, lists, dates, or semantic HTML issues |
| Authority gap | Relevant reviews, mentions, citations, links, or reputation signals |
| Action | Smallest useful change |
| Confidence | High, medium, or low with rationale |

## Page brief

Include:

- primary prompt cluster and buyer stage;
- canonical URL and conflict check;
- audience, category, and “best for” scope;
- direct-answer summary;
- question-led outline;
- evidence inventory with owners and review dates;
- comparison dimensions and disqualifying constraints;
- internal links from and to adjacent journey pages;
- structured-data opportunities that match visible content;
- independent validation needed;
- success metrics and re-test date.

## Evidence-block quality check

An evidence block passes when a reader can answer all of these:

1. What exact question does this section answer?
2. Is the answer visible immediately?
3. Which statement is independently checkable?
4. What is its scope and date?
5. Is the source primary or clearly attributed?
6. Can the passage be quoted without changing its meaning?
7. Does it avoid vague superiority claims?

## Prioritization

Use a transparent 1–5 scale for each factor:

- business value;
- citation gap severity;
- evidence readiness;
- current page authority;
- implementation ease;
- measurement confidence.

Explain the weights. Do not let a composite score hide a legal, factual, or reputational risk.

## Local-business extension

Check:

- complete and maintained Google Business Profile;
- consistent name, address, and phone data;
- real service-area information and proof;
- useful service and location pages rather than doorway variants;
- locally descriptive reviews requested without scripting false claims;
- locally relevant organizations, press, partnerships, and directories;
- mobile speed, calls, appointments, direction requests, and revenue attribution.
